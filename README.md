# 📄 Resume Builder Web App

A dynamic and user-friendly **Resume Builder** that allows users to create professional resumes in real-time and download them as a clean.

---

## 🚀 Features

* ✍️ Live Resume Preview (Real-time updates)
* 📑 Multi-section support:

  * Education
  * Skills
  * Projects
  * Work Experience
  * Achievements
  * Personal Details
* 🎯 Fresher / Experienced toggle
* 💾 Local Storage (Auto-save data)
* 📄 One-click PDF Download
* 📱 Mobile-friendly & responsive
* 📄 Auto page-break for long content

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & layout (A4 optimized)
* **JavaScript (Vanilla JS)** – Functionality
* **html2pdf.js** – PDF generation
* **Font Awesome** – Icons

---

## 📸 Preview

> Live preview updates instantly as you type.

---

## 💡 Usage

1. Enter your details in the form (left side)
2. Preview updates instantly (right side)
3. Add multiple sections (education, skills, etc.)
4. Click **Download PDF**
5. Your resume will be downloaded in A4 format

---

## 📄 PDF Features

* Clean A4 layout
* No background issues
* Auto page breaking for long resumes
* Maintains formatting across devices
